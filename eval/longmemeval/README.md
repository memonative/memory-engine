# LongMemEval-S: Memonative vs mem0

Head-to-head retrieval-quality benchmark.

## What this measures

Two metrics, computed identically on both systems:

- **recall@5** — fraction of questions where the top-5 retrieved
  memories include at least one tagged with a needle session id.
- **answer accuracy** — fraction of questions where an LLM answering
  with the retrieved memories matches the gold answer
  (judged by `gpt-4o-mini`).

Both systems run with **out-of-the-box defaults**. No prompt tuning,
no scoring-weight twiddling, no top-k sweeps. The point is a fair read
on retrieval quality, not a leaderboard.

## Prerequisites

1. **Postgres + Redis up** (Memonative side):
   ```bash
   docker-compose up -d db redis
   alembic upgrade head        # must report e5f6a0b1c2d3 (head) or later
   ```

2. **Qdrant** — not needed as a separate service. mem0's default
   self-hosted mode uses an embedded Qdrant that lives at
   `eval/longmemeval/data/qdrant_mem0/`.

3. **Eval deps** (kept separate from the main app):
   ```bash
   pip install -r eval/longmemeval/requirements.txt
   ```

4. **OpenAI key** in `.env` — used for embeddings, the answer LLM,
   and the judge. Budget ~$10–20 for a full run of both systems.

## Running

```bash
# Default: 100 questions stratified by question_type, both systems
PYTHONPATH=src python -m eval.longmemeval.runner

# Smoke test
PYTHONPATH=src python -m eval.longmemeval.runner --n 5 --run-id smoke

# Single system, custom subset
PYTHONPATH=src python -m eval.longmemeval.runner \
    --n 50 --systems memonative --question-types multi-session,knowledge-update

# After the runner completes, score and write RESULTS.md
PYTHONPATH=src python -m eval.longmemeval.scorer --run-id v1
PYTHONPATH=src python -m eval.longmemeval.scorer --run-id v1 --skip-judge   # recall only
```

Outputs land in `eval/longmemeval/data/runs/<run-id>/`:
  - `memonative.jsonl` / `mem0.jsonl` — raw per-question results
  - `sample.jsonl` — list of question_ids targeted (source of truth)
  - `RESULTS.md` — generated by the scorer

## Cost guards

- Hard kill-switch at $15 of estimated OpenAI spend (configurable).
- Run halts if either adapter hits a 20% error rate.
- All progress streamed to JSONL — interrupted runs resume from where
  they left off.
